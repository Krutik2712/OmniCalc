🔌 REST API Documentation

Integrate this Flask backend directly into external scripts, curl commands, or frontends.

POST /api/calculate

Executes mathematical calculation.

// Request Body
{
  "operation": "add",    // add, subtract, multiply, divide, power, modulo, sqrt
  "num1": 15,
  "num2": 35
}

// Response (JSON)
{
  "success": true,
  "result": 50,
  "expression": "15 + 35 = 50"
}
POST /api/convert

Converts measurement units.

// Request Body
{
  "category": "length",   // length, weight, temperature, data
  "value": 10,
  "from_unit": "kilometers",
  "to_unit": "miles"
}

// Response (JSON)
{
  "success": true,
  "result": 6.213712,
  "summary": "10 Kilometers (km) = 6.21371 Miles (mi)"
}
GET /api/units

Returns all supported categories and unit definitions.
